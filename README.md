# Лоза Admin (classic)

Обычный статический сайт: HTML + CSS + JS. Без Vite и сборки.

## Открыть локально

Вставь в браузер:

```
C:\Users\ricky\OneDrive\Рабочий стол\Loza\loza_admin\index.html
```

или через file URL:

```
file:///C:/Users/ricky/OneDrive/Рабочий%20стол/Loza/loza_admin/index.html
```

API по умолчанию: `https://api.loza-club.ru/api` (`config.js`).

## Возможности

- вход команды (OWNER / ADMIN / CURATOR)
- пост в ленту PWA: текст + картинка (upload)
- пользователи с аватаром Яндекса и **статусом оплаты**
- таблица платежей (готова к ЮKassa / Prodamus)
- управление чатами и сообщениями
