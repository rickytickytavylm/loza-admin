# Лоза Admin

Статическая панель команды. Уже ходит в боевой backend на Timeweb: `https://api.loza-club.ru/api`.

## Открыть

Локально: откройте `index.html` в браузере  
или положите папку на `admin.loza-club.ru` (CORS уже разрешён).

Вход: аккаунт с ролью OWNER / ADMIN / CURATOR.

## Что умеет

- живой статус Timeweb, ЮKassa, AI и push
- пост в публичную ленту PWA + картинка на сервер
- объявление в чат **ЛЕНТА** (только руководители, можно закрепить)
- пользователи: поиск, выдача тарифа, блок
- платежи
- модерация чатов
- киноклуб: рекомендация и вопрос для рефлексии
